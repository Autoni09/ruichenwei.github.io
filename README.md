# Personal Website

A personal website built with Astro and deployed to GitHub Pages.

## Features

- Personal homepage
- Portfolio projects
- Writing collection
- RSS feed
- SEO optimized
- GitHub Pages deployment

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Deployment

Automatically deployed to GitHub Pages via GitHub Actions on push to `main`.

## Tech Stack

- [Astro](https://astro.build/) — Web framework
- [Tailwind CSS](https://tailwindcss.com/) — Styling
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- Astro Content Collections — Content management
